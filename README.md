# paywallet-demo-app
PayWallet — a payment wallet designed to be broken<br>
A complete, single-file payment wallet that simulates the entire card andP2P lifecycle: Friends & Family vs Goods & Services fees, card declines, insufficient funds, 3D Secure step-up, buy-now-pay-later, savings interest, and fraud holds. One HTML file. No backend. No build step. No real money.<br>
